# Isshan Marwah — Portfolio

Portfolio website for Isshan Marwah, a Technical Artist and Game Developer working across Unreal Engine systems, procedural tools, Unity games, and game-ready 3D art.

## Live portfolio

[isshan11.github.io](https://isshan11.github.io)

## Featured work

- Unreal Engine editor and asset-cleanup tools
- Procedural ecosystem generation with UE5 PCG
- FPS combat and advanced AI systems
- Unity game development and implementation
- Environment, prop, character, animation, and VFX work

## Built with

- React
- TypeScript
- Vinext and Vite
- Lucide icons

## Run locally

```bash
pnpm install
pnpm dev
```

Then open the local address printed by the development server.

## Production build

```bash
pnpm build
```
